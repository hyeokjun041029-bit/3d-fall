# EggDrop Lab — 계란 낙하 물리 실험 시뮬레이터

다양한 완충재(15종)를 계란의 서로 다른 위치에 서로 다른 수량(1~10)으로 배치했을 때의 **2D 낙하 운동, 회전, 바닥 충돌 압축 및 완충 결과**를 계산하고 비교하는 한국어 웹 애플리케이션입니다.

## 주요 기능

- **낙하 조건 설정**: 2층~5층 선택, 가정 층고(기본 3.0m) 조정, 총 낙하 높이(m) 자동 계산, 계란 질량(기본 60g), 초기 기울기(°), 초기 회전 각속도(°/s), 중력 가속도(지구/화성/달 및 직접 입력), 공기 저항 반영 여부, 바닥 재질(콘크리트/나무 마루/잔디·흙/체육 매트) 설정
- **완충재 카탈로그 15종 및 위치 규칙**:
  - 뽁뽁이(에어캡), 스펀지, EVA 폼 시트, 골판지, 구긴 신문지, 키친타월, 솜, 헝겊/펠트, 종이컵, 종이 빨대 묶음, 벌집형 종이 완충재, 공기 완충 쿠션, 포장용 완충 충전재, 코르크 시트, 부직포
  - 재료별로 실제 부착 가능한 위치(전체 감싸기, 중간 띠, 아래 덧대기, 위 덧대기, 옆면 완충, 내부 채움, 알 받침, 외부 프레임)만 선택 가능하며, 동일 재료를 서로 다른 위치·수량으로 다중 배치 가능
- **2D 강체 낙하 및 충돌 애니메이션 (Canvas)**:
  - 좌측 전체 낙하 타워 트랙 + 우측 단면 확대 뷰
  - 반암시적(심플렉틱) 오일러 시간 적분 (비행 중 `1ms`, 바닥 근접·충돌 중 `20µs` 고정 스텝)
  - 무게중심(COM), 관성모멘트, 공력 항력 및 회전 감쇠, 48방향 비선형 스프링-감쇠 접촉 및 완충재 압축·복원 시각화
- **물리량 계산 및 A/B/C 비교**:
  - 총질량(계란/포장재 구분), 충돌 직전 속도, 운동량, 운동에너지, 1차 충돌 지속 시간(ms), 평균 충격력 추정치(N), 최대 압축량(mm), 반발 속도(m/s), 기울기 및 회전 각도, 맨 계란 대비 완충 효과(%), 상대 파손 위험 지표(0~100)
  - 여러 실험 구성을 저장해 나란히 비교하는 차트 및 테이블 제공
  - 시뮬레이션 예측과 별도로 **실제 실험 결과(깨지지 않음/균열/완전 파손, 실제 높이, 날짜, 관찰 메모)** 기록 지원

## 실행 및 검증 명령어

```bash
npm run dev        # 개발 서버 실행
npm run test       # Vitest 단위 및 시나리오 테스트 실행
npm run lint       # ESLint 코드 검사
npm run typecheck  # TypeScript 타입 검사
npm run build      # Next.js 프로덕션 빌드
```

## 환경변수 및 Supabase 마이그레이션 안내

현재 프로젝트에는 별도 사용자 인증(Auth) 세션이 없으므로, 보안 원칙(비인증 공개 읽기/쓰기 정책 금지)에 따라 기본적으로 브라우저 `localStorage`를 저장소로 사용합니다.

향후 Supabase Auth 연동 시:
1. `.env.example`을 참고해 `.env.local`에 `NEXT_PUBLIC_SUPABASE_URL`과 `NEXT_PUBLIC_SUPABASE_ANON_KEY`를 설정합니다.
2. `supabase/migrations/20261027000000_create_eggdrop_experiments.sql` 마이그레이션을 Supabase SQL Editor 또는 `supabase db push`로 실행하여 `public.eggdrop_experiments` 테이블과 본인 데이터만 접근 가능한 RLS 정책(`auth.uid() = user_id`)을 생성합니다.
